### Understanding Distributed Systems - Communication Introduction
- Network is the core and hearbeat of distributed systems
- The network is built layers by layers and can be understood as a stack. The lower the layer, the closer to the metal that layer is
  - This is refered to OSI model
- Some important layers from lower to top
  - Link layer: Ethernet, wifi and MAC address communication
  - Internet layer: packet is routed through the network, IP address
  - Transport layer: TCP
  - Application layer: the higher layer, HTTP, DNS
