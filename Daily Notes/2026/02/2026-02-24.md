### Operating System: Three Easy Pieces
- Operating System is a software that allows programs to interact with the device through the process called `virtualization`
- `Virtualization` is the process of transforming the physical resource of the machine to make a virtual version of itself
- Programs are able to interact with the device via API - system calls that the OS exposes
- OS can also be a resource manager since it will control the shared resources so that programs can all be optimimally used

### Understanding Distributed Systems - Network
- To avoid missing packets while transmitting data over the internet, we use TCP. TCP ensures the data transmission process is reliable and bytes are delivered in order
  - 3-way handshake
  - UDP is an alternative protocol - more lightweight but unreliable(data loss is expected)
- To make sure the data is not being interrupted, we introduce SSL ontop of TCP. This ensures encryption, integrity and authentication
- Systems use DNS to discover the IP address of the service from the host name and port number
