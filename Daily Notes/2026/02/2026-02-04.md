#### Understanding Distributed Systems - TCP
- TCP guarantes:
  - bytes are delivered in order
  - stability and reliability
  - avoid overwheling the network
- TCP guarantees byte ordering, stability and reliability by:
  - every packet sent from the senders and a sequence number
  - receiver has a checksum mechanism to guarantee packet is not corrupted
- Flow control is a backoff mechanism that prevents sender from overwhelming the network
  - This can be understood as a rate limiting at connection level
  - When receiver sends an ACK, it also sends the buffer size back to the sender. If the sender respects the protocol, it will avoid flooding the network
- Congestion window is computed by the sender to see the maximum bytes that can be sent without an ACK
  - Maximum capacity cannot be used as the connection first created
- UDP is a connectionless and lean alternative of TCP
