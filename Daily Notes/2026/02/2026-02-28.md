##### Linear Regression
- This is a regression learning algorithm that takes input as a linear combination of feature
- Problem Statements
  - The input of linear regression is a collection of labelled examples
  - The goal is to find the optimal values (a, b) to produce the optimal prediction from `y = a * x + b`
- Solution
  - Minimize the cost function
  - Loss function measures the error of a single training example
  - Cost function aggregates the the loss over the entire training set
