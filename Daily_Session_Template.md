## Notes for Using This Template

**How to Use:**
1. Copy this template before each study session
2. Save as: `Session_Logs/YYYY-MM-DD-Day-Topic.md`
   - Example: `Session_Logs/2026-01-22-Monday-CS.md`
3. Fill out during or immediately after your session
4. Be honest with recall scores
5. Update trackers based on this log

**Tips:**
- Fill out as you go, not all at end
- Be specific with page numbers
- Write insights while fresh
- Note confusing parts immediately
- Connect to previous learning

**Don't Worry If:**
- You don't fill out every section every time
- Some days have less to say
- Recall scores are low sometimes
- You need to adjust the template

This template is a tool to help you, not a burden!
