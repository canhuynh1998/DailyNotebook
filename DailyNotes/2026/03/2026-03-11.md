### Hundred Page ML Book
#### Chapter 1: Introduction
- Machine learning is the process of solving problem by gathering data and algorithmically building statistic model through the gathered data. This model is then used to solve practical problems
- There are 4 main types of learning
  - Supervised Learning
    - Goal: build a model that can take in input and produce a desired output
    - Supervised learnings take in labelled collection of input {x, y}, where x is called a feature vector and y is called a label(finite)
  - Unsupervised learning
    - Goal: build a model that take in input and either produce or transform to a value that is useful for solving other practical problem
  - Semi-supervised learning
    - Goal: similar to supervised learning
    - It contains a mix of labelled and unlabelled input. Theoretically, by having more input, the model has more information
  - Reinforcement Learning
    - A model can live in an environments. A state is an input. Model can perform action at every state. Different actions has different rewards
    - Goal: to learn the policy function. A policy function takes a state as input and produce an optimal action to perform in that state
      - Optimal action means maximizing the average reward
