### Codeforces
- [A. Boy or Girl](https://codeforces.com/problemset/problem/236/A)

```python
name = input()
lower_cases = [0] * 26
for c in name:
  idx = ord(c) - 97
  lower_cases[idx] += 1
counts = 0
for count in lower_cases:
  if count != 0:
    counts += 1
gender = "IGNORE HIM!" if counts % 2 != 0 else "CHAT WITH HER!"
print(gender)
```
