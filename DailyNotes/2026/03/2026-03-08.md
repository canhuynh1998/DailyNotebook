### OS: Three Easy Pieces
#### Introduction to OS
- Von Neumann architecture: processor fetches instructions from memory -> decodes the data -> execute the intructions -> repeat
- OS is the software that enables programs to interact with the devices(hardwares).
  - OS transforms the physical resources of the device to make a virtual version of itself
  - OS exposes system call API for programs to interact with the hardware
  - OS also manages the resources to determine who runs what at when
- CPU virtualization creates an illusion of the same processor being able to run multiple programms at once
  - Policies will determine which should be run
- Memory virtualization: each process has it own private address space. Even though the address is the same for 2 different processes -> The execution between the 2 won't be affected due to different address spaces
