## 🎯 Active Recall & Spaced Repetition System

### Active Recall Method (15 min daily)

**Level 1 - Basic Recall (5 min):**
- Close all materials completely
- Write everything you remember from reading
- Draw all diagrams from memory
- List key concepts without looking

**Level 2 - Explain Aloud (5 min):**
- Pretend you're teaching a colleague
- Explain concepts out loud
- Use simple language (Feynman technique)
- Identify gaps: What can't you explain clearly?

**Level 3 - Deep Testing (5 min):**
Answer these questions without any materials:
- What problem does this solve?
- What are the trade-offs?
- When would I use this?
- How does it connect to other concepts?
- Could I implement this from scratch?
- What would I do differently?

### Spaced Repetition Schedule

**Day 1: Initial Learning**
- Learn new concept deeply
- Take notes
- Do first active recall

**Day 2: First Review (Next day's warm-up)**
- 5 min warm-up: Recall yesterday's concepts
- WITHOUT looking at materials first
- Then verify with notes
- Score retention: X/10

**Day 7: Week Review (Saturday Session 2)**
- Review week's concepts
- Try full recall first
- Check notes after
- Score retention
- If poor (<6/10), schedule extra review

**Day 14: Two-Week Review (In warm-up period)**
- Brief 5 min review in warm-up
- Should be easier now
- Note what's forgotten

**Day 30: Month Review (Monthly assessment)**
- Saturday monthly review session
- Full recall test on month's learning
- Identify what needs more review
- Celebrate what's retained well

### Retention Scoring Guide

**9-10/10:** Perfect recall - Can teach this
**7-8/10:** Good retention - Minor gaps only
**5-6/10:** Okay retention - Need more review
**3-4/10:** Poor retention - Schedule immediate re-read
**1-2/10:** Failed recall - Re-learn from scratch

### Spaced Repetition Best Practices

1. **Never skip Day 2 reviews** - Most critical for retention
2. **Do reviews BEFORE looking at notes** - Tests real retention
3. **Be honest with scores** - Helps you identify weak areas
4. **If retention drops, schedule extra review** - Don't let it slip
5. **Connect new to old** - Always link to previous knowledge

## 💻 LeetCode Strategy (Engineering-Focused)

### Philosophy: Pattern Learning, Not Problem Grinding

**Goal:** Deep understanding of problem-solving patterns
**NOT:** Solving hundreds of problems quickly

**Monthly Target:** 12-16 problems (quality >> quantity)

### Wednesday Schedule Variations

**Weeks 1 & 3: LeetCode-Focused (60% problems, 40% project)**
```
5-10 min: Study pattern deeply
10-35 min: Solve 2-3 problems using pattern
35-40 min: Active recall - code pattern from memory
40-60 min: Document pattern + identify project applications
```

**Weeks 2 & 4: Project-Focused (40% problems, 60% project)**
```
5-15 min: Solve 1 key problem
15-40 min: Apply pattern to project code
40-60 min: Test, document implementation
```

### Pattern Learning Approach

**For Each Pattern:**

1. **Study (10-15 min)**
   - Read about pattern
   - Understand when to use
   - Learn time/space implications
   - See example applications

2. **Solve (20-30 min)**
   - 2-3 problems using pattern
   - Start simple, increase difficulty
   - Focus on understanding
   - Write clean, commented code

3. **Analyze (10-15 min)**
   - Why does this solution work?
   - What's the complexity?
   - Alternative approaches?
   - Where in real code?

4. **Document (10 min)**
   - Pattern template/pseudocode
   - When to use
   - Real-world applications
   - Problems solved

### After Every LeetCode Session

**Document:**
- Pattern learned today
- Problems solved (with links)
- Time/Space complexity
- Real-world applications
- Where this appears at work
- How to apply in current project

### 6-Month Pattern Progression

**Month 1: Arrays & Strings**
- Sliding Window (3 problems)
- Two Pointers (3 problems)
- Application: Data processing, string parsing

**Month 2: Pointers & Intervals**
- Fast & Slow Pointers (3 problems)
- Merge Intervals (3 problems)
- Application: Cycle detection, scheduling

**Month 3: Trees & Search**
- Tree BFS (3 problems)
- Tree DFS (3 problems)
- Binary Search (3 problems)
- Application: Hierarchical data, search

**Month 4: Backtracking & DP**
- Backtracking (3 problems)
- Dynamic Programming basics (3 problems)
- Application: Permutations, optimization

**Month 5: Graphs & More DP**
- Graph BFS/DFS (3 problems)
- Advanced DP (3 problems)
- Application: Networks, complex optimization

**Month 6: Review & Advanced**
- Review all patterns
- Hard problems combining patterns
- Application: Real project optimization

## 🔧 Adjustment Guidelines

**Reading slower than expected:**
- Reduce to 4-6 pages per session

- Understanding > Speed always
- Adjust completion estimates
- Focus on quality retention

**Project feels overwhelming:**
- Break into much smaller pieces
- Work on it every other week
- Absolutely no deadline pressure
- Focus on learning, not completion
- Pause if needed, resume when ready

**Can read more:**
- Increase to 30-40 min reading

- Tackle denser books

- Tackle harder LeetCode problems
